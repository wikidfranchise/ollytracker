What OllyComp DoesOllyComp is a web-based application (implemented as a single HTML file with embedded CSS and JavaScript) designed to query and display executive compensation data from U.S. Securities and Exchange Commission (SEC) filings. It is the fifth engine in the suite of 8 data tools (following OllyCortex), aimed at users in law enforcement, academia, and investigative journalism for analyzing C-suite pay structures. The tool runs on-demand, fetching historical data (from 2005 onward) based on user queries and presenting it in interactive visualizations.Core Functionality:Predefined and Custom Queries: Includes quick-search buttons for common filters (e.g., "$100M+ Club", "Big Tech Giants", "$1 Salary Heroes") that trigger predefined Lucene-style queries. Users can build custom searches via inputs for ticker symbol, CIK (Central Index Key), executive name, position (e.g., CEO, CFO), compensation range (min/max total), and year range (from/to). Queries are constructed as strings (e.g., "year:2024 AND total:[100000000 TO *]") and sent to the SEC API.
Data Fetching: Uses a POST request to the SEC API endpoint ('https://api.sec-api.io/compensation') with a hardcoded API key. Requests include query, pagination (from:0, size:50), and sorting by total compensation descending. Handles responses as JSON arrays of executive records.
Display and Visualization:Shocking Stats Dashboard: Top section with dynamic placeholders for highest pay, average CEO pay, CEO:worker ratio (using a hardcoded median worker salary of $75,000), and $1 salary CEOs. Stats are calculated from fetched data.
Leaderboard: Shows top 5 results as clickable items (name, position, ticker, total comp) that scroll to and highlight the corresponding detail card.
Executive Cards: Renders results as cards in a grid. Each card includes: exec name/position/ticker/year (with SEC link), total comp, breakdown (base, bonus, stock, options, other), and visualizations:Stacked horizontal bar for comp mix (percentages, colored segments with labels if >5%).
Individual vertical bars for each component.

Cards have classes for styling (e.g., mega-comp for >$50M, zero-comp for $1 salary).
Animations for loading (spinner), pulsing stats, and card interactions.

On-Load Behavior: Automatically runs a query for high earners (total >=$100M in 2023-2024) to populate the page initially.
UI/UX Elements: Green-gradient theme with yacht logo. Responsive design with compact nav/header. Quick-searches grouped by position/industry. Error handling shows messages; loading spinner during fetches.
Technical Notes:Client-side only; no backend or state persistence.
Uses hardcoded median salary for ratios; assumes API returns structured fields (e.g., salary, bonus, stockAwards).
No exports or advanced features; focuses on visualization.
Potential limitations: Fixed size:50, no pagination UI, assumes valid API responses.
