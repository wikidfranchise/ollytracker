

### What OllyFetch Does

OllyFetch is a web-based application (implemented as a single HTML file with embedded CSS and JavaScript) that functions as a comprehensive SEC (U.S. Securities and Exchange Commission) filing retrieval tool. It is the eighth and final engine in the suite of 8 data tools (labeled as "OllyFetch" in the code, though the nav suggests it might be "OllyAuditor" – assuming OllyFetch based on the query). Designed for investigators, it queries and downloads monthly batches of specific form types from EDGAR, with built-in chunking for large datasets, progressive loading, watchlists, advanced filtering, multiple views, pagination, and exports. It runs client-side, fetching data on-demand and displaying results interactively.

#### Core Functionality:
- **Input and Querying**: Users select year (2015–2025), month, and form type from a predefined map (e.g., 10-K, 8-K, Form D, 144, 3/4/5, 13F, 13D/G, etc.). Generates date range and builds Lucene queries (e.g., "formType:'10-K' AND filedAt:[2024-01-01 TO 2024-01-31]").

- **API Integration and Chunking**: Uses form-specific endpoints (e.g., /form-d, /form-144, /insider-trading) or general / endpoint. Hardcoded API key for POST requests. For counts >10,000, splits into date-based chunks (9500 each), fetching progressively with batching (50 records/batch). Displays count info, progress, and chunk status. Normalizes responses into uniform structure (formType, filedAt, accessionNo, companyName, cik, ticker, linkToFiling, details).

- **Progressive Display**: Loads and appends results in batches, updating UI in real-time. Supports grid (detailed cards), list (horizontal summaries), compact (minimal lines) views. Cards show company, CIK/ticker, filing date, form-specific details (e.g., offering amounts for Form D, holdings for 13F), and SEC links.

- **Filtering and Sorting**: Post-fetch filters by search (company/ticker/CIK/form), form type (dynamic dropdown), date range (today/yesterday/week/month), sort (date asc/desc, company, form). Watchlist toggle filters to watched tickers.

- **Watchlist Management**: Persistent (localStorage) ticker list. Add/remove via form, import/export JSON. Highlights watchlisted items in results. Clear all option.

- **Pagination and Views**: For >50 results, shows top/bottom pagination with first/prev/next/last and numbered pages (with ellipsis). Per-page options (50/100/200/500/all). View toggle buttons.

- **Exports**: JSON (with metadata), CSV (dynamic headers based on data fields, e.g., Total Offering for Form D), Excel (as CSV). Blob downloads with filenames including form/date.

- **UI/UX Elements**: Dark cyberpunk theme with yacht logo (white-filtered). Loading spinners, notifications (slide-in), animations (slideIn, spin). Responsive grids.

- **Technical Notes**:
  - Client-side; no backend. State in arrays (allFetchedFilings, filteredFilings, watchlist).
  - Handles form variations (e.g., SC 13D/G as one endpoint). Normalizes fields across APIs.
  - Chunking/batching with delays (200ms) to avoid rate limits. Progressive UI updates.
  - Limitations: Max 10k per query (chunks for more), fixed batch 50, no real-time.

OllyFetch excels at bulk retrieval of targeted SEC forms, with user-friendly post-processing for analysis and export.
